# graphcrackers.github.io

GraphCrackers의 첫 공식 웹사이트이자 **ARETE PROJECT** 소개 랜딩 페이지.
`main` 브랜치 루트를 GitHub Pages가 그대로 서빙한다. → https://graphcrackers.github.io/

이 문서는 "왜 이렇게 만들었는지"를 남겨두기 위한 기록이다. 나중에 다른 사람이(또는 몇 달 뒤의 우리가) 열어도
같은 기준으로 수정하고 이어갈 수 있도록, 배경·설계 원칙·구현상 결정·남은 일을 함께 적었다.

## 1. 배경과 목적

- ARETE PROJECT는 학생의 탐구 과정(문제의식 → 가설 → 탐구·분석 → 검증 → 발표·설득)을 대신 해주지 않고,
  단계마다 코칭하고 피드백하는 교육 서비스다. AI는 도구로 쓰되 판단과 사고는 학생이 한다는 것이 핵심 관점이다.
- 이 페이지의 목적은 하나다. **"대행"과 다르다는 관점을 전달하고 상담으로 연결하는 것.**
- 그래서 정보량을 늘리는 대신 스크롤 4개 섹션으로 메시지를 좁혔다.
  히어로 / 문제 제기·접근 방식 / 채널 링크 / 연락처.
- 주 독자는 모바일로 유입되는 학부모. 모바일 우선으로 설계했고, 데스크톱은 같은 레이아웃을 확대한 형태다.

## 2. 설계 원칙

| 원칙 | 이유 |
| --- | --- |
| 단일 파일(`index.html`)에 HTML·CSS·JS 인라인 | 빌드 도구·번들러·CI 없이 누구나 파일 하나만 고쳐 배포할 수 있게 |
| 외부 의존성 최소화 | 이미지 에셋 0개, 파비콘은 인라인 SVG data URI, 프레임워크 없음. 외부 요청은 폰트 CSS 2건뿐 |
| 정적 우선, JS는 장식만 | JS가 없거나 실패해도 모든 내용이 그대로 읽힌다(`no-js` 클래스 + `<noscript>` 폴백) |
| 조용한 톤 | 종이 느낌의 베이지 배경, 1px 구분선, 아이콘·그림자·컬러 강조 없음. 문장이 주인공이 되게 |

## 3. 디자인 토큰

`:root` CSS 변수로 관리한다. 색을 바꿀 때는 아래 값만 손대면 전체가 따라온다.

- 배경 `--bg: #F4EFE4` / 본문 `--ink: #26221C`(대비 약 13.7:1) / 보조 `--ink-soft: #5A5147`(약 6.7:1) / 구분선 `--line: #E2D9C6`
- 본문 한글: **Pretendard**(jsDelivr dynamic subset) — 가독성과 자간 균일성
- 라틴 대제목: **Noto Serif KR** — 위계를 만들기 위한 최소한의 세리프 대비. Google Fonts가 unicode-range로 쪼개 주므로 실제로는 라틴 조각만 내려온다
- 본문 폭 `--wrap: 680px`, 좌우 여백 `--pad-x: clamp(20px, 6vw, 40px)`
- 타이포·간격은 전부 `clamp()`로 유동 처리했다. 별도 미디어쿼리 브레이크포인트는 쓰지 않는다

## 4. 구현상 결정 사항 (수정 시 주의)

- **히어로 높이**: `min-height: 100vh` 폴백 + `100dvh`로 모바일 주소창 대응.
- **안전영역**: iOS 노치 대응으로 패딩에 `env(safe-area-inset-*)` 반영.
- **H1 한 줄 유지**: `white-space: nowrap` + `letter-spacing: 0.1em`, 자간 때문에 생기는 우측 쏠림은 `text-indent: 0.1em`로 보정.
  문구를 늘리거나 자간을 키우면 좁은 화면에서 잘린다(6절 참고).
- **등장 효과**: `.reveal` → IntersectionObserver로 `.is-in` 1회 부여(`threshold: 0.12`).
  히어로만 `document.fonts.ready` 이후 시작하고, 폰트 지연/실패 대비 1200ms 타임아웃을 둔다.
- **모션 최소화**: `prefers-reduced-motion: reduce`에서 등장 효과·셰브론 애니메이션을 전면 무효화.
- **한글 줄바꿈**: `word-break: keep-all` + `overflow-wrap: anywhere`.
- **터치 타겟**: 채널 버튼 최소 44×44px, 포커스는 `:focus-visible` 아웃라인으로만 표시.
- **외부 링크**: 전부 `target="_blank" rel="noopener noreferrer"`.
- **단계 나열**: `.steps`는 `<ol>`이고 화살표 대신 CSS `::after` 1px 선으로 연결한다(이미지·아이콘 없음).

## 5. 파일 구조

```
.
├── index.html   # 페이지 전체 (마크업 + 인라인 CSS + 인라인 JS, 약 380줄)
└── README.md    # 이 문서
```

별도 빌드 산출물이나 설정 파일은 없다. `main`에 푸시하면 GitHub Pages가 바로 배포한다.
로컬에서는 `index.html`을 브라우저로 열거나 `python3 -m http.server`로 확인한다.

## 6. 현재 상태 점검 (2026-08-11 실측)

배포된 페이지를 직접 확인한 결과 다음 항목이 확인되었다.

1. **채널 링크가 플레이스홀더 상태** — `{{INSTAGRAM_URL}}`, `{{SOOMGO_URL}}`, `{{KIMGWAIWO_URL}}`이 그대로 남아 있어
   Instagram·숨은고수·김과외 버튼을 누르면 상대경로로 해석되어 **404**로 간다. 공개 전 반드시 교체하거나 버튼을 숨긴다.
2. **`<meta name="robots" content="noindex">`가 아직 살아 있다** — 현재는 검색에 노출되지 않는 상태. 정식 공개 시 삭제.
3. **`og:image`가 없다** — 카카오톡·DM 등으로 링크를 공유하면 미리보기 카드가 비어 보인다.
4. **H1이 폰트 폴백 시 잘릴 수 있다** — `nowrap`이라 제목 너비가 폰트 메트릭에 그대로 의존한다.
   실측 결과 320px 폭에서 Pretendard/Noto Serif가 로드되면 딱 맞지만, 폴백 Georgia가 쓰이면 약 290px로 늘어나
   가용 폭(280px)을 넘고 `overflow-x: hidden`에 잘린다. 좁은 화면에서만 줄바꿈을 허용하거나 최대 폰트 크기를 조금 줄이는 편이 안전하다.
5. **랜드마크 태그가 없다** — `<main>`, `<footer>`가 없어 스크린리더 탐색 단서가 부족하다.
6. **전환 경로가 mailto 하나뿐** — 본문에서 "무료 시범 코칭"을 제안하지만 그 자리에 누를 수 있는 CTA가 없다.
7. **`404.html`이 없다** — 잘못된 주소는 GitHub 기본 404 화면이 뜬다.
