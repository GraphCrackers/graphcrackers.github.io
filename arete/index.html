Program / ARETE

성적이 아니라,
스스로 판단하는 힘

ARETE는 학생이 문제를 정의하고, 근거를 검토하고, 다른 사람과 논의하고, 자신의 언어로 표현하는 능력을 기르는 프로그램입니다.

대상과 형태커리큘럼수업 방식하지 않는 것

01 / Format

대상과 형태

중학교 2학년부터 고등학교 1학년까지를 대상으로, 한 명에서 네 명이 함께하는 대면 수업으로 운영합니다.

대상
중2–고1
인원
1:1–1:4
방식
소그룹 대면 · 총 8회

02 / Curriculum

네 개의 학습 트랙

8회 수업은 현대사회론, 탐구방법론, 신수사학, 자기경영론의 네 트랙을 연결합니다. 현재 세부 강별 원고는 검토 중이며, 확정되지 않은 제목과 내용을 임의로 게시하지 않습니다.

  1. Track A현대사회론
  2. Track B탐구방법론
  3. Track C신수사학
  4. Track D자기경영론

03 / Method

학생에게 판단을 돌려주는 수업

역플립러닝

학생이 먼저 문제를 만나고 시도한 뒤, 수업에서는 답보다 사고의 경로를 점검합니다.

소크라테스식 문답과 하브루타

질문, 설명, 반론을 오가며 자신이 아는 것과 아직 모르는 것을 구분합니다.

프로젝트 기반 학습

탐구 결과를 실제 글과 발표로 완성하며 계획과 실행을 연결합니다.

04 / Boundaries

우리가 하지 않는 것

대필과 결과물 대행을 하지 않습니다. 합격이나 성적 향상을 보장하지도 않습니다. 단기 결과를 대신 만드는 일은 학생이 다음 문제를 혼자 풀 수 있게 하는 교육과 다르기 때문입니다.
